Energy Consumption Forecasting System

This application analyzes historical electricity consumption, engineers time-series features (calendar, cyclical, lag, and rolling statistics), and trains multiple forecasting models — a naive baseline, moving average, linear regression, random forest, and XGBoost — comparing them on a strictly chronological train/validation/test split. The best model by validation RMSE is used to generate future forecasts, surfaced through an interactive dashboard.

All charts, metrics, and insights are computed from the actual dataset and the actual trained model — nothing on this site is hardcoded or fabricated.

Default Dataset

The reference dataset is the UCI Individual Household Electric Power Consumption dataset (Hebrail & Berard, 2006): minute-level readings from a single household near Paris, France, December 2006–November 2010. See data/README.md for how to download and prepare it. A synthetic sample dataset with the same schema ships with this repo so the project runs immediately without any download.

Limitations
  • Forecasts are statistical estimates, not guarantees, and cannot account for unexpected real-world events.
  • Confidence intervals (where shown) are derived from validation error, not formal prediction intervals for every model type.
  • Anomaly flags indicate statistical outliers, not confirmed equipment faults.
